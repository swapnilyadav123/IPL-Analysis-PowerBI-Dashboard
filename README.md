# 🏏 IPL Analysis Dashboard – Power BI

## 📊 Project Overview

The **IPL Analysis Dashboard** is an interactive data visualization project developed using **Microsoft Power BI**. The dashboard provides meaningful insights into Indian Premier League (IPL) matches, teams, players, and overall tournament performance.

The project focuses on transforming IPL data into interactive dashboards and visual reports that help users understand important trends and performance metrics.

## 🎯 Objectives

* Analyze IPL match and team performance
* Identify top-performing players
* Analyze team wins and losses
* Understand season-wise IPL trends
* Compare team performance
* Analyze runs, wickets, and match outcomes
* Create interactive and user-friendly Power BI dashboards

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Data Cleaning & Transformation**
* **Excel/CSV Dataset**

## 📈 Key Dashboard Insights

The dashboard includes analysis such as:

* 🏆 Total Matches
* 🏏 Total Runs
* 🎯 Total Wickets
* 👑 Top Run Scorers
* 🔥 Top Wicket Takers
* 🏆 Team-wise Performance
* 📅 Season-wise Analysis
* 📊 Win/Loss Analysis
* 🏟️ Venue-wise Match Analysis
* 👤 Player Performance

## 📊 Dashboard Features

### Team Analysis

Provides a comparison of different IPL teams based on their match performance and wins.

### Player Analysis

Highlights the performance of individual players based on runs, wickets, and other available statistics.

### Season Analysis

Shows how IPL performance and match trends changed across different seasons.

### Interactive Filters

Users can interact with the dashboard using filters and slicers such as:

* Season
* Team
* Player
* Venue
* Match Result

## 🔄 Data Preparation

The dataset was cleaned and transformed using **Power Query** before creating the dashboard.

The main data preparation steps included:

1. Importing the IPL dataset
2. Removing unnecessary columns
3. Handling missing values
4. Formatting data types
5. Creating calculated columns
6. Creating relationships where required
7. Building DAX measures
8. Creating interactive visualizations
